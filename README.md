# Login & Registration System

A simple **Login and Registration System built using C++**.
This project uses **file handling** to store and verify user credentials.

## Features

* User Registration
* Username validation
* Password validation
* Duplicate username checking
* User Login
* Credential verification
* Invalid username/password handling
* Menu-driven interface
* File handling using `fstream`

## Technologies Used

* C++
* File Handling
* `iostream`
* `fstream`
* `string`

## How It Works

1. Select **Register** to create a new account.
2. Enter a username and password.
3. The system checks whether the username already exists.
4. The credentials are stored in a file.
5. Select **Login** to verify the credentials.
6. Select **Exit** to close the program.

## Note

This project is created for learning purposes. Passwords are currently stored as plain text. A real-world application should use secure password hashing instead.
